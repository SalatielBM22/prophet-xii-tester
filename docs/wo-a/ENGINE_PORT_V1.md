# EnginePort v1

Contract baseline `2978fdc02c85aa413dc76cc468cebb05f5cecc2a`. Rust hosts share the safe, source-versioned interface in `crates/prophet-dsp-core/src/port.rs`. JNI, CLAP, VST3 and LV2 adapters translate their own ABI. Rust trait objects and enum layouts must stay within the same Rust build.

Prepare one independent instance off the audio thread. Negotiate two planar f32 output channels, integral sample rate 8,000–192,000 Hz, 1–1024 frames and 1x/2x/4x oversampling. Query the prepared instance for features. The host supplies PCM and ACK buffers. At most 256 events per call and 16 separately owned input streams are supported. Optional capabilities default off. A device or allocation budget that cannot accommodate preparation must fail before starting audio. Reconfiguration replaces the prepared engine at a transport boundary. Return oversampling latency in base-rate samples (0, 16, 24). The dry reverb path adds zero lookahead. Late reflections are tail, not plugin latency.

A block contains ordered offsets in `[0, frames)`. Render the prefix, apply all commands at the same offset in submitted order, then render that sample. The host carries commands at the right endpoint to the next block. Reject malformed block shape, offsets/order, origin or undersized ACK storage before changing state or either output. The caller supplies silence on rejected blocks. Individual unsupported/invalid commands receive an ACK. `applied` includes parameter changes with the same value. Revision is the parameter bank revision after the command, not a count of played notes. Oversampling automation uses off-thread prepare, never a parameter event.

Each origin owns a monotonically increasing, positive u32 serial. A replay at or below its watermark receives `duplicate`. An origin starts a new serial epoch only on a freshly prepared instance. Per-note identity is (origin, MIDI channel, key, noteId). Repeated notes need distinct noteIds for overlapping ownership. Raw MIDI 1 devices without instance IDs may use key as noteId and retrigger the same key. A host claims one physical device via native MIDI or browser MIDI, then forwards that canonical stream. Two independently stamped copies cannot be deduplicated by timing. Key-up with sustain transfers the note to pedal ownership. The damper (CC64) is channel-wide: a pedal held by any origin retains keys released on that channel by every origin (CCR-05); sostenuto stays per origin. Velocity-zero NoteOn means NoteOff. PanicOrigin releases only that origin. A GUI consumes snapshots without echoing notes.

The host timestamps actual callback arrival, xrun count and device buffering itself. Report unknown measurements as null. Snapshot frames count rendered samples since prepare, independent of transport seek. Split snapshot publication from serialization. File operations, locks, JSON, FFT, WebView, networking and allocation belong off the audio thread. Use bounded queues and return overflow explicitly.

The interface commit freezes wire meaning. Feature availability is negotiated on the implementation revision. See CONTROL_STATE_SCHEMA.md and CONTRACT_HANDOFF.md.
