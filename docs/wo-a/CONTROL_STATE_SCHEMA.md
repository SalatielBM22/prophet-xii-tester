# Control and state v1

The owned schema and fixtures in this directory define the off-thread bridge. `legacy-parameters.json` freezes RC1 IDs 0–82, units/ranges from PARAM_SPECS and plugin names p0–p82. Values are plain engineering units. Existing reverb_enabled and reverb_kill_tail plugin IDs are independent named controls. Numeric ID 83 appends Glide Enabled (0 or 1, host name p83). Keep the legacy array length 83 for existing adapters. Glide Time stays at 42 in seconds. Glide Mode stays at 78 (0 constant rate, 1 constant time). To decode RC1, initialize the enable bit from its stored time > 0.0005 s. New state stores the bit separately, including when off with nonzero time. During playback Off applies immediately without changing stored time or law.

For v1 use bounded MIDI/control commands and per-command ACKs. JS renders u64 revisions and frame counters as decimal strings. Validate JSON off-thread. Unknown major versions and unsupported fields that affect sound must produce diagnostics before recall. Hosts retain the last valid state on decode failure. Old presets resolve to Classic2 and LegacyRC1 version 1. Factory preset data is immutable. Report instance-local held vs sustained notes explicitly. The twelve DSP voice records describe release and unison members separately from physical key state. Advertise optional capture, analyzer, sequencer, live routing, hot-swap and state extensions individually only after the adapter supports them.

Reverb v1 reports enabled, spill/kill, frozen, dormant and zero dry-path latency. Frozen tail may be unbounded. Finite RT60 is a parameter, not a guaranteed tail termination time. XY is the closed diamond |x|+|y|<=1. Reject invalid coordinates. GUI submits bounded gestures at sample offsets. Topology and pattern preparation occur outside process. The renderer owns the musical clock. Unknown host measurements are nullable.
